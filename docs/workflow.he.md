# תהליך העבודה

הסקיל `video-orchestrator` מנהל את העריכה. Claude מקבל את ההחלטות: מה המשמעות של כל חלק,
הסיפור, איפה נכנסות גרפיקות, נוסח הכתוביות. `tools/vf.py` עושה את העבודה המכנית.
כל מה ששייך לסרטון אחד נמצא ב-`projects/<name>/`, שלעולם לא נכנס לקומיט.

## שני מצבים

| | מונחה חומר מצולם | מונחה תסריט |
|---|---|---|
| מתאים ל | ראיונות, מרואיינים מול מצלמה, אירועים, טיולים, המלצות לקוחות | פרומו למוצר, סרטוני הסבר, פרסומות עם קריינות |
| מה קובע את התזמון | מה שנאמר בחומר המצולם | הקריינות, מקטע אחר מקטע |
| הכתוביות עוקבות אחרי | הדיבור בחומר המצולם | הקריינות |
| ויזואליה אופיינית | החומר המצולם, צילומי אווירה (b-roll), כותרות תחתונות, נתונים | הקלטות מסך, צילומי מוצר, תרשימים, נתונים |

פרומו משלב לעיתים קרובות את שניהם: קטעים מראיון עם פתיח מוקרא וגרפיקות.

## מונחה תסריט, שלב אחר שלב

| # | שלב | מה קורה | פקודה |
|---|---|---|---|
| 1 | תסריט | `script.md`, פסקה אחת לכל מקטע; שורות `>` הן הערות ויזואליות | — |
| 2 | קול | כל מקטע מוקרא על ידי ספק TTS, ואז הכול מחובר, מתוזמן ומתומלל | `vf.py voice <name> --provider … --voice …` |
| 3 | ויזואליה | חלקים שאורכם מתאים למקטעים: הקלטות מסך (`exact`), חומר מצולם, כרטיסי גרפיקה | `story.json` + `"voiceover"` |
| 4 | טיוטה ← הערות ← גרסה סופית | כמו במצב מונחה חומר מצולם | `vf.py render` |

מתחילים עם הקול החינמי `say` (macOS) כדי לתזמן את העריכה, ועוברים לקול בתשלום בגרסה הסופית.
רק מקטעים שהשתנו מוקראים מחדש.

## מה הרינדור עושה, לפי הסדר

1. **חלקים**: חלקי חומר מצולם נחתכים בדיוק של פריים, הברות היסוס ושתיקות מוסרות כשמבקשים,
   והחיתוך מוצמד אל מחוץ למילים. חלקי גרפיקה מרונדרים מתבניות. שניהם נשמרים במטמון.
2. **חיבור** עם המעבר, בגודל הפלט (pad או crop).
3. **צילומי אווירה (b-roll)** כקטעי חיתוך מעל העריכה; הקול ממשיך.
4. **מראה**: LUT או תיקון צבע.
5. **שכבות עליונות**: גרפיקה בתנועה עם רקע שקוף (כותרות תחתונות, נתונים), תמונות, הלוגו.
6. **אודיו**: קריינות (החלפה או מיקס), ואחר כך מוזיקה שמונמכת מתחת לדיבור.
7. **כתוביות**: מתוזמנות מחדש על העריכה הסופית, נצרבות מימין לשמאל, קריוקי לבחירה. שפות
   נוספות מוכנסות כרצועה (mux) או נצרבות.
8. נרמול **עוצמה** (רק ברינדורים סופיים).
9. גיליון תמונות ממוזערות של התוצאה, לבדיקה.

## איפה מתקבלות ההחלטות

| החלטה | מי | איפה |
|---|---|---|
| הסיפור, הסדר, מה לחתוך | Claude מציע, אתם מאשרים | `story.json` |
| תיקוני נוסח בכתוביות | Claude | `captions.cues` |
| צבעי המיתוג, לוגו, גופן | אתם | `brand.json` |
| מוזיקה | אתם (ברישיון) | `music/` + `"music"` |
| הקול והספק | אתם | הדגלים של `vf.py voice` |
| תרגומים | Claude כותב, אתם בודקים | `translations/<lang>.json` |

בכל שלב, `vf.py status` מראה איפה כל פרויקט עומד ומה הצעד הבא. כל רינדור מסתיים בבדיקת איכות אוטומטית (אורך, גודל, ערוצים, כתוביות).
